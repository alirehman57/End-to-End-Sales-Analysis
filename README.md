# End-to-End-Sales-Analysis
End-to-end Sales Data  Analysis project on a Regional Sales dataset. Performed data cleaning, wrangling, and EDA using Pythonn (Pandas, Matplotlib, Seaborn).Analyzed revenue trends, profit margins, channel mix, product and regional performance, and delivered actionable insights  with business recommendations.
